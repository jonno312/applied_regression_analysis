79  Interpretation

79.1 Learning Objective

Interpret the coefficients in Poisson regression.

79.2 Lesson

79.2.1 Intercept

Recall that, in Poisson regression, we assume \[ \log\lambda_i = \beta_0 + \beta_1 X_{i1} + \cdots + \beta_p X_{ip} \text{.} \]

What happens when all the covariates equal zero? \[ \begin{align*} \log\lambda_i &= \beta_0 + \beta_1 X_{i1} + \cdots + \beta_p X_{ip} \\ \log\lambda_i &= \beta_0 + \beta_1 (0) + \cdots + \beta_p (0) \\ \log\lambda_i &= \beta_0 \\ \lambda_i &= \exp(\beta_0) \\ \end{align*} \]

So, \(\exp(\beta_0)\) is the rate when all the covariates equal zero.

79.2.2 Non-Intercept Coefficients

How do we interpret the non-intercept coefficients? Suppose observation \(i\) has \(X_{i1} = x\) and observation \(j\) has \(X_{j1} = x + 1\). For each \(k \ne 1\), \(X_{ik} = X_{jk}\). In words, the two observations are identical except for the first covariate, where the \(j\)th observation exceeds the \(i\)th observation by one unit. Then \[ \begin{align*} \log \frac{\lambda_j}{\lambda_i} &= \log \frac{p_j}{1-p_j} - \log \frac{p_i}{1-p_i} \\ &= \beta_0 + \beta_1 X_{j1} + \cdots + \beta_p X_{jp} - \left(\beta_0 + \beta_1 X_{i1} + \cdots + \beta_p X_{ip}\right) \\ &= \beta_0 + \beta_1 (x+1) + \cdots + \beta_p X_{jp} - \left(\beta_0 + \beta_1 x + \cdots + \beta_p X_{ip}\right) \\ &= \beta_0 + \beta_1 x + \beta_1 + \cdots + \beta_p X_{jp} - \left(\beta_0 + \beta_1 x + \cdots + \beta_p X_{ip}\right) \\ &= \beta_1 \text{.} \end{align*} \] By exponentiating both sides of this equation, we see \[ \begin{align*} \log \frac{\lambda_j}{\lambda_i} &= \beta_1 \\ \frac{\lambda_j}{\lambda_i} &= \exp(\beta_1) \text{.} \\ \end{align*} \]

In words, \(\exp(\beta_1)\) is the rate ratio comparing two populations that are identical except that one exceeds the other by one unit on the first covariate. If \(\exp(\beta_1) > 1\), the rate is greater in the population with the higher value of the first covariate; if \(\exp(\beta_1) < 1\), the rate is lesser in the population with the higher value of the first covariate; if \(\exp(\beta_1) = 1\), the rate is the same in both populations.

79.2.3 Example

This data set comes from A Canadian Study of Smoking and Health–Second Report. These are the variables:

  • age_group: Age group, with the following levels:
    • 40-44
    • 45-49
    • 50-54
    • 55-59
    • 60-64
    • 65-69
    • 70-74
    • 75-79
    • 80+
  • smoke_group: Smoking status, which has the following levels:
    • Never smoked
    • Cigar and pipe only
    • Cigarette and other
    • Cigarette only
  • population: The number of people in that age group who had that smoking status, at the start of the six-year follow-up period.
  • deaths: The number of people in that age group who had that smoking status and who died by the end of the six-year follow-up period.

Each row corresponds to a unique combination of age_group and smoke_group.

These are the modeling decisions I’ve made for this data set:

  • Our outcome will be deaths. Note that this is a count, which is appropriate for the Poisson distribution.
  • The offset will be log(population / 1000). This means we will be modeling the expected number of deaths per thousand people.
  • If I don’t make any changes, the reference age group will be <30 because it’s first alphabetically. This is not a great idea because it’s the smallest age group.
tapply(X = d$population,
       INDEX = d$age_group,
       FUN = sum)
  <30 30-34 35-39 40-44 45-49 50-54 55-59 60-64 65-69 70-74 75-79   80+ 
  526  8682 12592  8742  5732  4465  8956 11756  8147  4720  2335  1269

I’m going to make 35-39 the reference group because it’s the largest age group.

d$age_group <- relevel(x = as.factor(d$age_group),
                       ref = "35-39")
  • If I don’t make any changes, the reference smoke group will be cigar_and_pipe_only because it’s first alphabetically. This is not a great idea because it’s the smallest smoke group.
tapply(X = d$population,
       INDEX = d$smoke_group,
       FUN = sum)
cigar_and_pipe_only cigarette_and_other      cigarette_only        never_smoked 
               4897               39198               26764                7063

I’m going to make never_smoked the reference group because it’s a larger smoke group and because it’s logical to want to compare different forms of smoking to never having smoked

d$smoke_group <- relevel(x = as.factor(d$smoke_group),
                         ref = "never_smoked")
  • I’m going to regress the outcome on age_group and smoke_group without an interaction term. I am primarily concerned with the association between smoke group and deaths, controlling for age. I’m willing to assume (at least for now) that the association between smoke group and deaths is the same, regardless of age group.
mod_01 <- glm(formula = deaths ~ age_group + smoke_group + offset(log(population / 1000)),
              family = poisson,
              data = d)

79.3.2.2 Part (b)

If I fit this model, how will the exponentiated coefficients change from part (a)?

mod_04 <- glm(formula = deaths ~ age + malignant + offset(log(population)),
              family = poisson,
              data = d3)
TipSolution

Only the exponentiated intercept will change. It will be the estimated number of deaths per person in the reference group, rather than per ten people, so it will be one-tenth of the value for part (a).

Since the non-intercept exponentiated coefficients represent rate ratios, using per person or per ten people won’t change them.
