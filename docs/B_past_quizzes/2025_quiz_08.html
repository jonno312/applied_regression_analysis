113.1 Problem 1

Suppose you have three multiple linear regression models that differ only in what explanatory variables they include. The three models are:

  • Model 1: \(E(Y_i|A_i,B_i,C_i,D_i) = \beta_0 + \beta_1 A_i + \beta_2 B_i + \beta_3 C_i + \beta_4 D_i\);
  • Model 2: \(E(Y_i|A_i,B_i,C_i) = \beta_0 + \beta_1 A_i + \beta_2 B_i + \beta_3 C_i\); and
  • Model 3: \(E(Y_i|A_i,B_i) = \beta_0 + \beta_1 A_i + \beta_2 B_i\).

Please answer the following questions based on these three models. Assume all four of our assumptions for linear regression are met for each model.

113.1.1 Part (a)

(4 points) Suppose \(D_3\) is missing in the data set, i.e., the third participant is missing a value for the fourth explanatory variable. There is no other missing data in the data set. Which of the following metrics could you use to compare Model 1 and Model 2? Select all that apply.

  1. \(R^2\)
  2. \(R_\text{adj}^2\)
  3. Likelihood
  4. AIC
TipSolution

i and ii

Since these two models are fit on different observations, you can’t use likelihood-based methods to compare them. Model 2 is fit on all \(n\) observations and Model 1 is fit on \(n - 1\) observations, i.e., all the observations except the third.

This doesn’t matter for \(R^2\) because it’s a ratio. The contribution of the third observation is removed from both the numerator and denominator of the \(R^2\) for Model 1. This also doesn’t matter for \(R^2_\text{adj}\) for similar reasons.

For a more thorough explanation: the key here is that Model 1 and Model 2 were fit using different datasets (Model 1 using \(n - 1\) participants, Model 2 using all \(n\) participants). Therefore, the likelihood of Model 2 is based on the distribution of the all of the observations, while the likelihood of Model 1 is based on the distribution of a subset of those observations. As a result, the two models aren’t properly comparable using likelihood-based metrics, since those essentially rely on checking which model has a higher likelihood \(\mathcal{L}\) based on the same distribution of observations.

113.1.2 Part (b)

(4 points) Suppose \(D_3\) is missing in the data set, i.e., the third participant is missing a value for the fourth explanatory variable. There is no other missing data in the data set. Which of the following metrics could you use to compare Model 2 and Model 3? Select all that apply.

  1. \(R^2\)
  2. \(R_\text{adj}^2\)
  3. Likelihood
  4. AIC
TipSolution

i, ii, iii, and iv

Since Models 2 and 3 don’t use the fourth explanatory variable, it doesn’t matter if one of the observations is missing the fourth explanatory variable. Both Models 2 and 3 can be fit on all \(n\) observations.

113.1.3 Part (c)

(4 points) Suppose \(A_3\) is missing in the data set, i.e., the third participant is missing a value for the first explanatory variable. There is no other missing data in the data set. Which of the following metrics could you use to compare Model 2 and Model 3? Select all that apply.

  1. \(R^2\)
  2. \(R_\text{adj}^2\)
  3. Likelihood
  4. AIC
TipSolution

i, ii, iii, and iv

Since both Models 2 and 3 use the first explanatory variable, the third observation couldn’t be used to fit either of them. So, Models 2 and 3 will be fit on the same \(n - 1\) observations.

113.1.4 Part (d)

(4 points) Suppose you use a likelihood ratio test to compare Model 1 to Model 3. You obtain a p-value of 0.00001. What is a reasonable conclusion from this result? Select all that apply.

  1. Model 3 is at least as good as Model 1.
  2. Model 3 fits the data better than Model 1.
  3. Model 2 is at least as good as Model 3.
  4. Model 1 fits the data better than Model 3.
TipSolution

iv

The null hypothesis is that the smaller model is the true model. With such a low p-value, we would reject this hypothesis and conclude that the larger model, Model 1, fits the data better than the smaller model, Model 3.

113.2 Problem 2

(4 points) If \(X\sim\text{Poisson}(\mu)\) then \(X\) could represent (select all that apply):

  1. A count.
  2. The time to an event.
  3. The outcome of a coin toss.
  4. Any decimal value.
TipSolution

The support of \(X\) is \(\{0,1,2,3,\dotsc\}\), and a count is the only real world quantity in this list that matches that.

113.3 Problem 3

(4 points) If \(X\sim\text{Poisson}(\mu)\) then \(\mu\) is (select all that apply):

  1. The standard deviation of \(X\).
  2. The variance of \(X\).
  3. The probability that \(X = 1\).
  4. The mean of \(X\).
TipSolution
  1. and (d)

113.4 Problem 4

(4 points) Suppose you conduct quasi-Poisson regression and get an estimated dispersion parameter of \(\hat{\phi} = 100\). This is evidence that (select all that apply):

  1. The mean is equal to the variance.
  2. The mean is not equal to the variance.
  3. The data are Poisson-distributed.
  4. The data are not Poisson-distributed.
TipSolution
  1. and (d)

With quasi-Poisson regression, we assume that \(Var(Y) = \phi E(Y)\). With the Poisson distribution, \(Var(Y) = E(Y)\). So, if \(\phi\) is large, that’s evidence that the data are not Poisson-distributed.

113.5 Problem 5

(1 point) When there is overdispersion, we expect the standard errors for quasi-Poisson regression to be

the standard errors for Poisson regression. (Select one.)

  1. the same as
  2. less than
  3. greater than
TipSolution

With more variability in the data, we expect lower precision in estimating our coefficients.

113.6 Problem 6

(1 point) True or false: R does not produce an AIC for quasi-Poisson regression because quasi-Poisson regression does not use a likelihood.

TipSolution

True

Quasi-Poisson regression doesn’t correspond to an actual distribution. It uses a quasi-likelihood instead of a likelihood.

113.7 Problem 7

(1 point) True or false: Assuming everything else stays the same (e.g., the data, the formula), if you only change from Poisson to quasi-Poisson regression, the estimates of the coefficients will not change.

TipSolution

True

113.8 Problem 8

(1 point) True or false: If \(t_1 = t_2 = t_3 = \cdots = t_{n-1} = t_n = 1\) then we do not need to include an offset in Poisson regression.

TipSolution

True

\(\log 1 = 0\)

113.9 Problem 9

(1 point) True or false: It is appropriate to use the \(R^2\) for model selection when only some of the assumptions of linear regression are met.

TipSolution

True

The \(R^2\) is just a function of the observed values, the fitted values, and the average. It doesn’t rely on any assumptions.

113.10 Problem 10

(1 point) True or false: It is appropriate to use the \(R^2_\text{adj}\) for model selection when only some of the assumptions of linear regression are met.

TipSolution

True
